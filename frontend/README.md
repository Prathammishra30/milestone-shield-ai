# MilestoneShield AI — Frontend Dashboard

This package contains the single-page application for MilestoneShield AI, built with React 19, TypeScript, Vite, Tailwind CSS v4, and AG Grid.

## Available Scripts

- `npm run dev`: Starts the local development server at `http://localhost:5173` with proxying to `http://localhost:3001/api`.
- `npm run build`: Type-checks and builds the production bundle in `dist/`.
- `npm run typecheck`: Runs `tsc -b --noEmit` to verify type safety.
- `npm run preview`: Locally previews the production build.
